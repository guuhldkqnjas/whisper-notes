## 🤖 Overview

Whisper Notes records your voice and transcribes it using OpenAI Whisper running entirely on your device, producing accurate text notes without sending audio to any server.

Whether you're a newcomer or a veteran, Whisper Notes provides the tools you need to get the most out of your ai tools experience. Designed for Windows and macOS, it delivers a seamless, high-performance workflow.

## ✨ Key Features

| Feature | Description |
|---|---|
| **100% Local** | Whisper runs on-device so audio never leaves your machine |
| **Auto Punctuation** | Adds commas, periods, and paragraph breaks automatically |
| **Multi-Language** | Transcribes over 90 languages with high accuracy |
| **Export Options** | Save notes as plain text, Markdown, or copy to clipboard |
